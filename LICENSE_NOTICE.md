# Licence / Notice compatibility file

The repository's legal information is now split into dedicated files:

- [`LICENSE`](LICENSE) — permission status for the project's original code/documentation;
- [`NOTICE.md`](NOTICE.md) — unofficial fan-project notice;
- [`THIRD_PARTY_NOTICES.md`](THIRD_PARTY_NOTICES.md) — external data/services and known licence/terms status;
- [`PRIVACY.md`](PRIVACY.md) — privacy behaviour;
- [`SECURITY.md`](SECURITY.md) — security reporting and constraints.
